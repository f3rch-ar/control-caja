# TP2: Procesamiento de Registros de Tránsito

## 📌 Descripción
Sistema en JavaScript para el procesamiento de datos de vehículos en una ruta mediante métodos funcionales de arreglos. El programa procesa un arreglo de registros para generar un reporte de multas utilizando `map()`, filtra los vehículos infractores con `filter()`, y calcula estadísticas totales (kilómetros recorridos y recaudación en multas) utilizando `reduce()`.

## 🚀 Uso
Abrir el archivo correspondiente en el entorno de ejecución de JavaScript o visualizar los resultados directamente en la consola del navegador (`F12`) según la ejecución del archivo `tp2.js`.
